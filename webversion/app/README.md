# gowrite webversion app

Sprint 1 delivers a usable writing MVP:
- Single chapter editor using Web Components
- Autosave to localStorage
- Reload recovery
- Status bar with word count/cursor/save state
- Basic shortcuts: Ctrl/Cmd+S and Ctrl/Cmd+K placeholder

## Scripts
- `npm run dev`
- `npm run build`
- `npm run typecheck`
- `npm run lint`
- `npm run test`
- `npm run test:e2e`
